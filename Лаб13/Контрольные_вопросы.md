# Контрольные вопросы — ЛР №13

**1. Что такое исключение в Java?**
Событие, нарушающее нормальный ход выполнения программы — ошибка времени выполнения (runtime error), возникающая при выполнении кода (деление на ноль, обращение к null, выход за границы массива и т.д.).

**2. Какая иерархия классов исключений в Java?**
Все исключения наследуются от `Throwable`:
- `Error` — системные ошибки (`OutOfMemoryError`, `StackOverflowError`), не обрабатываются;
- `Exception` — проверяемые исключения (`IOException`, `SQLException`);
- `RuntimeException` — непроверяемые (`NullPointerException`, `ArithmeticException`, `ArrayIndexOutOfBoundsException`).

**3. В чем разница между checked и unchecked исключениями?**
- `checked` (`IOException`, `FileNotFoundException`) — проверяются компилятором: метод обязан либо обработать (`try-catch`), либо пробросить (`throws`);
- `unchecked` (`RuntimeException` и его наследники) — компилятор не проверяет, обрабатывать их не обязательно.

**4. Какие ключевые слова используются для обработки исключений?**
`try`, `catch`, `finally`, `throw`, `throws`.

**5. Что такое try-catch-finally?**
Конструкция: `try` — блок с потенциально опасным кодом; `catch` — обработка конкретного типа исключения; `finally` — блок, выполняющийся всегда (при исключении, без него и даже при `return`), обычно для освобождения ресурсов.

**6. В чем разница между throw и throws?**
- `throw` — оператор, генерирует исключение в конкретном месте: `throw new MyException("msg");`
- `throws` — часть сигнатуры метода, объявляет, что метод может выбросить исключения: `void readFile() throws IOException;`

**7. Что такое блок finally и когда он выполняется?**
Блок завершения, выполняется всегда: и при исключении, и при нормальном завершении `try`, и при `return`. Единственное исключение — завершение процесса (`System.exit()`).

**8. Как создать собственное исключение?**
Наследовать `Exception` (checked) или `RuntimeException` (unchecked), вызвать `super(message)`, при необходимости добавить поля и геттеры:
```java
public class MyException extends Exception {
    public MyException(String message) { super(message); }
}
```

**9. Что такое try-with-resources?**
Конструкция Java 7+: ресурс объявляется в скобках `try` и автоматически закрывается в обратном порядке при выходе из блока. Ресурс должен реализовывать `AutoCloseable`.

**10. Как обработать несколько типов исключений?**
Несколькими последовательными блоками `catch` (от специфичного к общему), либо объединением типов через `|` в одном блоке (multi-catch).

**11. Что такое множественный catch (multi-catch) в Java 7+?**
Один блок `catch` для нескольких типов исключений, обрабатываемых одинаково:
```java
catch (NumberFormatException | NullPointerException e) { ... }
```
Такие типы не должны быть в отношении наследования.

**12. Какая ошибка возникает при делении на ноль?**
`java.lang.ArithmeticException: / by zero` (целочисленное деление).

**13. Что происходит с исключением, если его не обработать?**
Оно всплывает по стеку вызовов до `main`; если и там не обработано — поток завершается, программа останавливается с кодом ошибки и печатью stack trace.

**14. Как получить сообщение об ошибке из исключения?**
`e.getMessage()` — текст сообщения; также `e.toString()` (класс + сообщение) и `e.printStackTrace()`.

**15. Что такое стек вызовов (stack trace)?**
Порядок вложенных вызовов методов в момент выброса исключения. Печатается `printStackTrace()`, показывает класс, метод, файл и номер строки, где возникло исключение — главный инструмент отладки.

**16. Как использовать try-with-resources с несколькими ресурсами?**
Перечислить ресурсы через `;` в скобках `try`; они закрываются в обратном порядке:
```java
try (FileInputStream fis = new FileInputStream("in.txt");
     FileOutputStream fos = new FileOutputStream("out.txt")) {
    ...
} catch (IOException e) {
    ...
}
```
