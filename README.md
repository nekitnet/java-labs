# Лабораторные работы по Java

Учебные лабораторные работы по дисциплине «Основы кроссплатформенного программирования».

## Структура

| Ветка | Лабораторная работа | Тема |
|-------|---------------------|------|
| `lr6` | Лаб6 | Инкапсуляция. Модификаторы доступа |
| `lr7` | Лаб7 | Статические поля и методы |
| `lr8` | Лаб8 | Наследование и полиморфизм |
| `lr9` | Лаб9 | Абстрактные классы |
| `lr10` | Лаб10 | Интерфейсы |
| `lr11` | Лаб11 | Переопределение методов |
| `lr12` | Лаб12 | Коллекции |
| `lr13` | Лаб13 | Исключения |
| `lr14` | Лаб14 | Работа с файлами |
| `lr15` | Лаб15 | Git и GitHub |

## Запуск

Каждая лабораторная работа — отдельный Maven-проект:

```bash
cd Лаб6
mvn compile exec:java -Dexec.mainClass=Lab6
```

## Сборка

```bash
mvn package
```
